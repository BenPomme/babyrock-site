Prenez un jour de repos pendant que BabyRock gère les messages courants

Dans cette démo, Leo prend un jour de repos. BabyRock répond aux questions courantes sur les horaires et le paiement par carte, tandis qu'une demande de table pour huit parvient sur son WhatsApp avec l'heure de fermeture, 22 h.

Les questions courantes n'ont pas à interrompre le jour de repos du responsable. BabyRock s'occupe des messages du quotidien. Quand une demande nécessite son attention, elle arrive sur son WhatsApp avec le contexte pour choisir la bonne réponse.

Comment ça marche

  1. Laissez BabyRock répondre aux questions courantes sur les horaires et le paiement.
  2. Envoyez au responsable les demandes qui nécessitent son attention.
  3. Donnez-lui le contexte nécessaire pour décider de la suite.

Ce que vous allez voir

Un jour sans les messages courants

Leo prend un jour de repos. Les questions sur les horaires et le paiement par carte reçoivent une réponse sans qu'il ait à intervenir dans chaque message.

Une demande qui nécessite le responsable

Une cliente demande une table pour huit demain à 20 h. La demande parvient à Leo sur WhatsApp.

Le responsable décide

La réponse mentionne la fermeture à 22 h, pour que Leo ait le contexte nécessaire pour décider de sa réponse.
