Actualiza el horario de tu web y de Google desde WhatsApp

En esta demo, Mesa Coffee abre mañana a las 12 en lugar de las 9. Luis pide por WhatsApp actualizar la web y el perfil de Google. BabyRock prepara el cambio, Rosalia pide aprobación y Luis responde: «Yes, publish it.»

Un cambio puntual de horario no tiene que perderse entre herramientas. Luis envía la nueva hora por WhatsApp. BabyRock reúne el cambio para la web y el perfil de Google, Rosalia lo revisa y Luis aprueba la publicación con una sola respuesta.
